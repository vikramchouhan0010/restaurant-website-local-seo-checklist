# Restaurant website and local SEO checklist

A checklist for a restaurant or cafe that wants its website to bring orders and bookings from local search. It comes from the work BigShark SEO, a web and SEO agency in the Chandigarh and Mohali region, does for food businesses.

## Website basics

- [ ] Menu as real text on the page, not only an image or PDF
- [ ] Address, phone, opening hours and map on every key page
- [ ] A tap-to-call and WhatsApp button that works on mobile
- [ ] Pages load fast on a mobile connection
- [ ] Photos with descriptive file names and alt text

## Local SEO

- [ ] Google Business Profile complete, with correct hours, categories and photos
- [ ] The same name, address and phone number on the website and on every directory
- [ ] A page for each location or outlet
- [ ] Reviews requested politely after a meal, and answered
- [ ] Schema markup for restaurant, menu and opening hours

## Ordering and booking

- [ ] Clear link to table booking or online ordering
- [ ] Contact form tested weekly

## Measure

Track calls, WhatsApp taps, direction requests and bookings that start from search, not only visits.
